# Personal Budget Tracker – Project Problem 1

This repository contains my solution for **Project Problem 1: Personal Budget Tracker**.  
The goal of this assignment was to analyze the scenario, reverse-engineer the program behavior shown in the video, and produce:

- An IPO Chart  
- Pseudocode  
- A clear understanding of the program flow and user interaction  

---

## 📌 Project Description

The Personal Budget Tracker is a console-based tool that allows a user to:

- Log income in three categories:
  - Design
  - Coding
  - User Documentation
- Log expenses in three categories:
  - Software
  - Equipment
  - Workspace
- View a financial summary showing:
  - Total income
  - Total expenses
  - Net balance
  - Monthly status (profit, loss, or break-even)

All menus, validation loops, and outputs were recreated based on the user interaction shown in the project video.
